# Post-Mortems

The `memory/post-mortems/` directory stores detailed logs of resolved errors and architectural pivots.

## Purpose
- **Analyze:** Understand the root cause of past mistakes.
- **Learn:** Record lessons learned from project experiences.
- **Avoid:** Prevent recurring errors and architectural regressions.
- **Improve:** Continuously improve project workflows and standards.
- **Document:** Maintain a detailed history of project-specific learning.
