# Rules: AA-UX (The Key)

- **Seedless Onboarding:** Every user account must be accessible via email/social login.
- **ERC-4337 Standards:** Use standard EntryPoints, Bundlers, and Paymasters.
- **Gasless Transactions:** Implement gasless transactions for high-yield vaults.
- **Passkey Verification:** Every SmartAccount must support Passkey signatures for maximum security.
- **Onboarding Latency:** The account creation process must be completed in < 30 seconds.
- **Social Recovery:** Every SmartAccount must have a clear recovery path for the user.
