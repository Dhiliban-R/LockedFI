# AI Models Rules

- **Protection:** Never log, print, or commit API keys or sensitive credentials.
- **Ethics:** Adhere to ethical AI guidelines and project-specific constraints.
- **Privacy:** Rigorously protect all user data and project-specific information.
- **Transparency:** Provide clear, concise explanations for all AI-driven actions.
- **Safety:** Ensure all AI executions run within secure, isolated environments.
