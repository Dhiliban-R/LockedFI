# Rules: AI-Security (The Sentinel)

- **Mempool Vigilance:** The AI-Sentinel must monitor the mempool for all incoming vault transactions.
- **Anomaly Detection:** Identify malicious signatures and flash-loan-assisted attacks.
- **Circuit Breaker:** The `pause()` function must be accessible only to the AI-Sentinel's address.
- **Latency Optimization:** The sentinel script must respond with sub-second latency.
- **Zero-Trust:** Every withdrawal must be audited for suspicious patterns before execution.
