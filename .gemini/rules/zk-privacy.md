# Rules: ZK-Privacy (The Ghost)

- **Data Sovereignty:** No sensitive user data (ID, bank statements) should ever touch the blockchain or a database.
- **ZK-Verifier Integration:** All "High-Yield" deposits must require a valid ZK-Proof.
- **Circuit Verification:** All Circom circuits must be mathematically proven and gas-optimized.
- **Privacy Policy:** Every user proof must be private, showing only that the criteria are met.
- **Snarkjs/Groth16:** Use standard, well-audited Groth16 for all production-ready proofs.
