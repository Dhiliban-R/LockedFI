# Gemini CLI: The Autonomous Sovereign Vault Framework

## 1. Project Mission: The "Triple Crown" Strategy
To architect and deliver a production-ready, institutional-grade DeFi protocol that solves the industry's three most critical challenges: **Security (AI), Privacy (ZK), and Usability (UX).**

### Strategic Pillars
1.  **The Key (UX - ERC-4337):** Seamless, seedless onboarding via Account Abstraction.
2.  **The Ghost (Privacy - ZK-Proofs):** Private financial verification without data leakage.
3.  **The Sentinel (Security - AI Agent):** Real-time, autonomous defense against on-chain attacks.

## 2. Engineering Directives
- **Zero-Trust Architecture:** Every interaction must be verified by ZK-proofs or AI guardians.
- **Formal Verification (FV):** Mission-critical smart contracts must be mathematically proven.
- **Privacy-First Data:** No sensitive user information should ever touch a database or blockchain.
- **Event-Driven Execution:** The system must respond autonomously to on-chain anomalies.

## 3. Governance & State
- `CHANGELOG.md`: The single source of truth for all project progress.
- `PLAN.md`: The deterministic scratchpad for verifiable task execution.
- `.gemini/state/session.json`: The shared memory bus for inter-agent context.
- `.gemini/state/repo-map.txt`: The repository mapping for high-signal context.

## 4. Security Policy
- **Human-In-The-Loop (HITL):** ALL write and execute operations require explicit human approval.
- **Isolated Execution:** Automated tasks must run within virtual environments.
- **Secrets Management:** NO credentials, API keys, or private keys are allowed in the repository.
