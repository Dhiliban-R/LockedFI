# Skill Creator SKILL

The `skill-creator` skill is a meta-agent for generating new, project-specific skills and capabilities.

## Workflow
1. **Analyze:** Understand the project's needs and architectural patterns.
2. **Synthesize:** Analyze project experiences and lessons learned.
3. **Generate:** Dynamically write new `SKILL.md` files for expanding skills.
4. **Update:** Refine existing skills based on ongoing project needs.
5. **Expand:** Broaden the framework's capabilities through continuous learning.
