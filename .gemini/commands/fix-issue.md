# Fix Issue Command

The `fix-issue` command automates the process of identifying, reproducing, and fixing reported issues.

## Workflow
1. **Analyze:** Parse the reported issue and identify the root cause.
2. **Reproduce:** Empirically reproduce the issue in a local environment.
3. **Plan:** Formulate a grounded plan for fixing the issue.
4. **Execute:** Apply targeted, surgical changes to resolve the issue.
5. **Verify:** Confirm the success of the fix through automated tests.
